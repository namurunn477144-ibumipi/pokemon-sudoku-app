# ポケモン すうどく（いぶちゃん＆みーちゃん）

こどもと おとなが あそべる すうどくアプリです。

## こども（パートナー：イーブイ）
- **きのみ 4×4**：すうじの かわりに 4しゅるいの きのみを いれる
- **すうじ 4×4**：1〜4 の すうじで
- **すうじ 6×6**：1〜6 の すうじで
- まちがえると、おなじ ものが ある マスを ひからせて おしえてくれる
- 1もん とくと きのみが 1こ ひらく（なかよし度・しんか）

## おとな（9×9）
- むずかしさ 4だんかい（かんたん／ふつう／むずかしい／げきむず）
- メモ・もどす・けす・ヒント・まちがいチェック（オン／オフ）
- タイム と ベストタイム（ヒントなしで クリアした とき）の きろく
- とちゅうの もんだいは ほぞんされ、つぎに ひらいた ときに つづきから できる

もんだいは まいかい じどうで つくり、こたえが かならず 1つに なる ものだけを だします。

- ポケモン・きのみの え、なきごえ：PokeAPI
